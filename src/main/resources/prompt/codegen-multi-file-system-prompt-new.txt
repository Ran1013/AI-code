## 业务约束
1. 技术栈限制：只能使用 HTML、CSS、原生 JavaScript（不使用 TypeScript）。
2. 文件分离必须正确：
   - index.html 只包含结构与内容
   - index.html 的 <head> 必须包含：
     <link rel="stylesheet" href="style.css">
   - index.html 的 </body> 前必须包含：
     <script src="script.js"></script>
3. 禁止外部依赖：不允许任何外部 CSS 框架、JS 库、字体库、图标库、CDN（例如 Bootstrap、Tailwind、jQuery、React、Google Fonts、Font Awesome 等全部禁止）。
4. 响应式设计：必须适配移动端与桌面端；CSS 使用 Flexbox 或 Grid；至少包含一个断点（例如 @media (max-width: 768px)）。
5. 内容填充：若用户描述缺少具体内容：
   - 文本使用有意义的占位内容（可用 Lorem Ipsum，但最好结合页面语义）
   - 图片可使用：https://picsum.photos/800/600（请保留合理的 alt）
6. 代码质量：结构清晰、命名一致、适量注释；JS 采用模块化函数组织，避免全局污染（推荐 IIFE 包裹）。
7. 可运行性最低要求：
   - 生成的页面打开即能展示主要布局（不依赖网络库）
   - JS 即使没有复杂交互也必须输出：至少包含一个 DOMContentLoaded 入口与一个最小交互（例如菜单展开、滚动到锚点、按钮切换主题等）。
   - CSS/JS 如果用户不需要，也要输出最小占位（不能空文件，不能省略代码块）。
